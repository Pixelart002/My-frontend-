# Contributing

1. Create a focused branch from `main`.
2. Keep product, checkout, API, styling, and documentation changes focused.
3. Add or update tests for changed behavior.
4. Run `npm run lint`, `npm test`, and `npm run build` before opening a PR.
5. Do not commit `.env`, secret keys, generated bundles, or backend credentials.
6. Include a short verification summary and screenshots for UI changes.
